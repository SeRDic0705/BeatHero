# 씬 구조 및 흐름 설계 명세

## 씬 구성

```
TitleScene
GameScene
```

층 이동은 씬 전환 없이 GameScene 내에서 몬스터 데이터 교체 + UI 연출로 처리.

---

## TitleScene

- 타이틀 화면
- 게임 시작 버튼 → GameScene 로드 (1층부터)
- 설정 버튼 → Settings 패널 오버레이 오픈

---

## GameScene

### 진행 흐름

```
GameScene 로드
  → 1층 진입 연출 (UI 페이드 인 등)
  → 전투 루프 시작

전투 루프
  → CallPhase → ResponsePhase → 패턴 전환 (반복)
  → 몬스터 HP ≤ 0 → 층 클리어
  → 플레이어 HP ≤ 0 → 게임오버

층 클리어
  → 층 클리어 연출 (UI)
  → 다음 몬스터 데이터 교체, 층수 +1
  → 다음 층 진입 연출
  → 전투 루프 재시작

게임오버
  → 게임오버 UI 표시
  → 확인 → TitleScene으로 복귀
```

### 일시정지 (ESC 키)

ESC 키 입력 → 전투 일시정지 + 포즈 메뉴 오픈

**포즈 메뉴 항목:**
- 게임 재개 → 일시정지 해제, 전투 재개
- 설정 → Settings 패널 오픈 (포즈 메뉴 위에 오버레이)
- 메인화면으로 나가기 → TitleScene으로 복귀

---

## Settings 패널

TitleScene / 포즈 메뉴 양쪽에서 공유 사용 → **프리팹으로 제작**

설정 항목 및 구현 방식은 [Settings_Design.md](Settings_Design.md) 참고.

---

## 전투 HUD 레이아웃

```
┌─────────────────────────────────────┐
│  [플레이어 HP]  [층수]  [몬스터 HP]  │
│                                     │
│          (전투 그리드)               │
│                                     │
│    [마나]                           │
│         ──────[비트 바]──────        │
└─────────────────────────────────────┘
```

| 위치 | 요소 |
|---|---|
| 좌측 상단 | 플레이어 HP 바 |
| 상단 중앙 | 현재 층수 |
| 우측 상단 | 몬스터 HP 바 |
| 하단 좌측 (비트 바 좌측) | 마나 게이지 (최대 5) |
| 하단 중앙 | 비트 바 (4분음표 기준 시각적 메트로놈) |

## 요약

| 씬 | 역할 |
|---|---|
| `TitleScene` | 타이틀 + 게임 시작 + 설정 접근 |
| `GameScene` | 런 전체 (모든 층, 클리어, 게임오버, 일시정지) |
| `Settings 패널` | 프리팹, TitleScene + 포즈 메뉴에서 공유 |
